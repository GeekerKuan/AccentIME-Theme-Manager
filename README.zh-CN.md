# AccentIME Theme Manager 0.5.0 Preview

原生 x64 Win32 程序，用于管理微信输入法 2.1.3.18 的候选项选中提示色和 WinUI 3 风格语音输入界面。

## 安装与使用

1. 运行 `AccentIME.ThemeManager-x64.msi`，按向导安装。
2. 从开始菜单打开 **AccentIME Theme Manager**。
3. 选择颜色，或点击“读取系统色”。
4. 如需自动同步，勾选“跟随 Windows 强调色（事件驱动）”。
5. 点击“应用”，在修改发生前接受 Windows UAC。

“恢复原文件”会关闭自动跟随并放回首次应用前保存的原始 `app.so`。卸载 MSI 时也会先执行同一恢复流程；恢复失败会阻止卸载，以免丢失恢复工具。

## 性能设计

- C++20 原生 Win32，静态链接 MSVC 运行库，无 .NET、Electron 或 WebView 依赖。
- 前台程序不常驻。
- 自动跟随使用 `RegNotifyChangeKeyValue` 阻塞等待 Windows 强调色变化，不使用定时轮询。
- 仅在强调色实际变化时重新生成等长补丁并重启微信输入法服务；语音界面本身仍完全由微信原进程绘制。

## 安全边界

- 仅支持微信输入法 2.1.3.18 的已验证正式文件。
- 应用前验证 SHA-256 和目标 Dart AOT 字段。
- 新文件必须等长，且除 3 个已验证颜色字段和 3 个识别气泡专用字段（总白名单 32 字节）外逐字节一致。
- 识别文本气泡改为 12 像素圆角的 WinUI 3 深色材质，保留原有柔和阴影并移除底部尖角；白色文字保持高对比度。
- 语音按钮使用强调色调和的深色中性渐变；微信原有麦克风、音量动画、识别文字、滚动和完成提示逻辑均未修改。
- 永久备份和恢复清单位于 `%ProgramData%\AccentIME\Backups`。
- 使用同目录暂存与 `ReplaceFileW` 原子替换。
- 恢复直接替换回备份原文件，不执行额外的恢复后 SHA-256 复核。
- 腾讯升级微信输入法或目标文件变化后默认拒绝操作。

本预览构建未使用商业代码签名证书，Windows 可能显示“未知发布者”。

## 请人工测试的四项

1. 安装 MSI 后，确认“设置 → 应用 → 已安装的应用”出现本软件，开始菜单可以启动。
2. 应用一个明显颜色（如 `#7C3AED`），在记事本输入 `test`，确认候选项选中色变化；再启动语音输入，确认按钮背景同步变色、白色麦克风和圆点清晰。
3. 连续说一段话，确认识别文本气泡为 12 像素圆角深色矩形、没有底部尖角，文字更新和自动滚动正常。
4. 开启自动跟随并更改 Windows 强调色，确认颜色更新；最后点击“恢复原文件”，确认原气泡样式和原绿色均恢复。

反馈时只需说明每项“通过/失败”，失败项附错误文字或截图。
